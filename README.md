# Технологии и методы программирования

Учебный репозиторий по дисциплине "Технологии и методы программирования".

В репозитории собраны учебные программы на Python и C++, реализующие обработку битовых строк и выполнение логической операции `AND` для двух двоичных последовательностей длиной до 8 бит.

## Содержимое репозитория

- `lab1.cpp` - первая версия программы на C++ для ЛР №1
- `lab2.py` - первая версия программы на Python для ЛР №2
- `lab3.cpp` - доработанная версия программы на C++ для ЛР №3
- `lab4.py` - доработанная версия программы на Python для ЛР №4
- `lab5.cpp` - программа на C++ с использованием классов для ЛР №5
- `BitString.h` - заголовочный файл класса `BitString`
- `BitString.cpp` - методы класса `BitString`
- `lab7.cpp` - программа на C++ с динамическим массивом для ЛР №7
- `BitStringDynamic.h` - заголовочный файл класса `BitString` для ЛР №7
- `Source.cpp` - реализация класса для ЛР №7
- `lab6.py` - программа на Python с использованием класса для ЛР №6
- `BitStringPy.py` - класс для работы с битовыми строками в Python
- `lab8.py` - программа на Python с конструкторами и деструктором для ЛР №8
- `BitStringPy2.py` - класс для работы с битовыми строками в Python для ЛР №8
- `.idea/` - Python 
- `.vscode/` - VSCode

## Структура лабораторных работ

### ЛР №1

Файл `lab1.cpp` содержит начальную версию программы. В ней:

- запрашивают у пользователя две битовые строки
- проверяют корректность введенных данных
- проверяют, что длина каждой строки не превышает 8 символов
- дополняют строки нулями слева до длины 8 бит
- выполняют поразрядную логическую операцию `AND`
- выводят результат на экран

## Проверка корректности ввода

Программы обрабатывают следующие ситуации:

- длина строки больше 8 символов
- присутствуют символы, отличные от `0` и `1`

Если ввод некорректен, программа выводит сообщение об ошибке и завершает работу.

## Сборка и запуск C++-программ

### ЛР №1

```bash
g++ lab1.cpp -o lab1
./lab1
```

### ЛР №3

```bash
g++ lab3.cpp -o lab3
./lab3
```

### ЛР №5

```bash
g++ lab5.cpp BitString.cpp -o lab5
./lab5
```

### ЛР №7

```bash
g++ lab7.cpp Source.cpp -o lab7
./lab7
```

При выборе ввода из файла программа читает две строки из файла `input.txt`.

После выполнения результат записывается в файл `output.txt`.

## Работа в Visual Studio Code

В папке `.vscode` добавлены настройки проекта:

- `tasks.json` - задача для сборки `lab5.cpp` и `BitString.cpp`
- `launch.json` - конфигурация запуска
- `c_cpp_properties.json` - базовые настройки среды C++

Это позволяет открывать репозиторий в Visual Studio Code и запускать C++ программу через встроенные инструменты редактора.

## Работа в PyCharm

В папке `.idea` находятся служебные файлы проекта PyCharm. Они сохранены в репозитории для удобного открытия проекта в той же структуре, в которой он разрабатывался.
